# Desktop - Black Friday (Next.js)

Projeto Next.js simples com a landing page da promoção Black Friday.
Contém uma página principal com formulário que captura leads (ainda não integrado a um backend).

## Como rodar localmente

1. Instale dependências:
   ```bash
   npm install
   ```

2. Rode em modo de desenvolvimento:
   ```bash
   npm run dev
   ```

3. Abra no navegador:
   http://localhost:3000

## Próximos passos recomendados
- Integrar o formulário a uma API (Google Sheets, Airtable, Firebase ou e-mail).
- Colocar o projeto no GitHub e publicar no Vercel para hospedagem grátis.
